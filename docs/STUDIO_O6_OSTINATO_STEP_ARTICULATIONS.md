# O6 — Advanced ostinato steps and articulation routing

Base O5 09a9e69fc053b273760ff9f6eab998e6149819bb; standalone, Linux and Intel macOS workflows passed. O6 does not merge the Universal Instrument System branch.

## Editing
Select a cell, then Step details, or right-click it. Sustain cells 1–16 extends a note across following inactive cells (the gate applies to the final cell); it cannot cross the row-cycle boundary. Strikes 1–8 subdivide one cell into equal retriggers; a tied span and ratchets are mutually exclusive. Timing offset ±450 thousandths of the cell width moves the onset relative to its original beat, bounded to the row cycle. Probability 0–100% uses a deterministic integer hash of row ID, cycle number and step index. It is decided when compiling a finite render, not randomized on each live callback. Pattern data migrates from schemas 1–4 to schema 5; prior defaults preserve behavior. The normal Apply step editor preserves advanced settings.

## Articulations and expression
The advanced dialog lists user-authored Articulation Palette mappings on the exact current instrument instance and channel. A step stores the mapping ID, not a guessed MIDI note or a label. Leave unchanged sends no switch and does not restore a prior technique. Audition resolves all generated references before starting, rejects missing/ambiguous/unsafe/channel-mismatched bindings and keyswitch pitches that collide with musical notes, and aborts on mapping changes. Different simultaneous techniques on a shared track/channel are rejected, including overlapping explicit and unchanged events. Controller assignments send their saved fixed values before the note; unsafe pedal, channel-mode, bank and parameter-selection CCs are excluded. Keyswitch note-on precedes the musical note-on and is held until the last generated note using that articulation on the channel ends; normal stop releases owned switches with notes. This is appropriate only for patches compatible with that switch timing, and no guaranteed lead time or patch-specific release/reset behavior is implemented. Confirm mappings for the actual loaded patch before audition; no automatic vendor inference. No separate arbitrary expression curves or per-step continuous profile control editor yet.

M45–M51 attachments use StudioInstrumentAttachment/profile element IDs and schema-2 Binding, rather than the legacy StudioArticulations instance-specific Mapping XML. O6 uses the existing baseline's legacy palette. Native sampler auto-derived mappings that are not saved in the palette are not exposed here. Full Universal Instrument profile integration, semantic translation, compound keyswitches and native sampler-specific routing are deferred until branch consolidation. Check Pattern validates core rhythm/overlap only; Audition performs actual mapping resolution. Live playback remains O4's stopped-transport, message-thread audition with O5 conducting. Timing is not sample-accurate. Do not play manual MIDI on destination instruments while auditioning.
