# M41 — Deep Black

Select View > Color Theme > Deep Black. Appends theme index 7; prior saved indices and default are preserved. Graphite Red retains its M40 main palette. Both hardware themes share the rotary, fader, transport and articulation rendering; the docked and floating audition keyboard now uses the hardware palette and controls, including live note overlays. Other themes keep the legacy keyboard styling.

Deep Black uses #050505 canvas, #0C0C0C panels, #000000 wells and #101010 timeline; warm white labels, restrained red-orange ticks and red record face. Native title bars and specialized hard-coded editor colors are outside this pass. No audio, project state or MIDI mappings are changed.
