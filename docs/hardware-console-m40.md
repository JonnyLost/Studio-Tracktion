# M40 — Hardware console appearance

The product owner's photographed M-Audio Oxygen 25 is the visual reference. Graphite Red (persisted theme index 1) now uses neutral matte charcoal surfaces, warm white labels, small warm red-orange graduations, grey fader caps and black recesses. Record has a red face and white symbol; active transport controls have a small status light. Selected Inspector articulation pads use ivory with dark ink. The other six themes retain their existing styling. Select View > Color Theme > Graphite Red. No change to default theme or saved preference index.

Shared JUCE rotary renderer, button background and mixer/Inspector vertical fader drawing use geometry only. No image assets, audio state, routing, MIDI mapping, track colours, or editor layouts are changed. Existing instrument outline assets are retained. Hardware mode is isolated by theme index; the Inspector flags are ignored outside hardware mode.

The appearance metrics suite checks the hardware palette, white-on-red and ivory/dark ink contrast, tick contrast and active status contrast. Manual acceptance on the Intel MacBook: compare all main workspaces, mixer and inspector at 100% and largest text; check knob readability across range, fader endpoints and unity indication, transport idle and active states, selected articulation pads, keyboard focus, disabled states, and switching back to every existing theme. Specialized fixed-colour editors, native title bars, and external AU windows are not comprehensively reskinned. No screenshots or actual macOS build are claimed by this change until CI/local verification.
