# O6 — Articulations and advanced step properties

Base O5 09a9e69fc053b273760ff9f6eab998e6149819bb. O5 standalone and Linux checks passed at inspection; Intel was running. This branch remains based on the independent Ostinato stack; no merge with M45–M51.

## Advanced step editing
Right-click a matrix cell to open Advanced Step. Set repeated strikes (1–8), timing offset (−250 to +250 thousandths of the cell), probability (0–100%), and a named articulation/mapped fixed controller. Apply commits just that cell via project undo. The existing gate field accepts 1–4000 thousandths; values above 1000 extend a note across cells. Ratchets require gate at most 1000, applied per strike. For a held note, leave subsequent cells inactive; a later same-pitch attack retriggers. These are extended gates rather than explicit notation ties. The advanced property marker and density dot identify configured cells. Basic edits preserve advanced settings.

Schema 5 preserves all O1–O5 properties and adds strikes, offset, probability and mapping ID; older patterns migrate to one strike, zero offset, 100% probability, no articulation change. Probability is evaluated once per row/cell/cycle using a stable integer hash, so all strikes of that step are included or omitted together. Recompiling the same pattern produces identical results. There is no user seed control yet. Fractional strikes derive from absolute integer boundaries, offsets move the entire step, negative starts clip at the pattern origin and notes clip at the finite render end. Bounded candidate evaluation and polyphony prevent pathological render sizes. Density and intensity remain live O5 admission/velocity controls; probability is determined before audition.

## Named articulation audition
The selector reads the existing Studio articulation palette XML on the selected arrangement track for its unique current instrument instance and MIDI channel. Select a saved mapping by name; the cell stores the stable mapping ID, not a guessed library-specific MIDI number. No mapping means no change to the currently selected articulation. A missing, ambiguous, invalid or changed mapping is refused before audition or stops the run. Track and instrument identity and mapping snapshots are checked throughout audition. Native sampler group-rule mappings and the newer Universal Instrument Profile snapshot are not yet bridged on this isolated branch. The selector supports fixed note keyswitches or fixed controller mappings (excluding pedals/channel-mode messages); it is not an arbitrary continuous expression lane.

For a note keyswitch, O6 injects its note-on before the musical note-on in the same message-thread dispatch, then releases the musical note and keyswitch at note end or Stop. A CC mapping emits its fixed value immediately before the note; it is not automatically reset. Only admitted musical notes trigger their mapping. This is a best-effort initial switch strategy: libraries requiring lead time, short pulses, special release behavior or compound keyswitches need later integration and physical testing. The system blocks musical pitch collision with switch pitches and overlapping generated notes on an articulation-controlled track/channel to avoid changing articulation mid-note. This intentionally limits polyphonic articulated patterns; use separate MIDI channels or nonoverlapping gates. Untagged notes may inherit the last selected articulation; no automatic return to a default. The physical controller isolation and stopped-transport audition limits of O4–O5 still apply. No sample-accurate playback or MIDI printing yet.

## Verification
Regression fixtures cover migration, extended gates, absolute ratchet timing, offsets, deterministic probability, schema round trip, named request preservation, missing bindings, reserved keyswitch pitches, unsafe controller types, and overlapping articulated channels. The standalone and full native CI workflows cover O6. The advanced dialog, actual keyswitch order and hosted library responses have not yet been verified on the user's hardware. No branch merge.

O7 adds harmony, chord following and arpeggiation. Subsequent integration must bridge the Universal Instrument System (M45–M51), add library-specific switch timing, shared MIDI ownership, transport synchronization and performance capture before production use.
