# M48 — Live Universal Instrument View and transport

Based on M47 commit 3af7e3dc2bb78b14b42eabd71a292a6b9103d878. M46 Intel and Linux checks passed; M47 CI was still running when implementation was reviewed. No existing branch merged.

## Workflow

1. Load an Audio Unit instrument, select its track, and stop playback. In Instruments > Instrument Designer create a profile from that track, choose articulations and controls, assign MIDI in M47, audition and save the profile.
2. Choose Instruments > Use Saved Instrument Profile. Only saved profiles with the same hosted plug-in identifier/version and a patch name are selectable. Confirm the actual loaded patch, MIDI channel and slot. Studio does not load another instrument or change the current ARIA patch.
3. Studio stores an undoable project-local snapshot on the track, including its exact instrument instance ID. Global profile edits do not silently change projects. Reapply the updated saved profile to update the snapshot. Detach Instrument Profile removes the snapshot and restores the previous workspace presentation.
4. The Composer View's existing performance area displays the compact instrument strip on profiled tracks. Controls honor Transport visibility; Articulations Only hides performance controls, and Hide Performance Panel hides the strip. Mixer, picture scoring and docked Atelier preserve their previous layouts. Select another track to change surfaces automatically. Tracks without compatible profiles retain the previous performance panel and articulation strip.
5. Click Full Instrument in the strip or Instruments > Universal Instrument View. A resizable floating horizontal window follows the selected track. It has vector artwork, an articulation matrix, configurable buttons/knobs/vertical faders, native mixer volume/pan/room controls, and utility buttons for Designer, Mixer, Rooms and original AU. Channel/library/patch information can be collapsed. Controls scroll if necessary; no arbitrary maximum display count beyond the profile's existing 128-element bound.
6. Both views share last-sent values and channel-specific selected articulation. Refreshing, switching tracks, loading a profile and opening the window never send MIDI. A keyswitch sends note-on and a delayed note-off to the original instance, with cancellation on context changes. CC, pressure and pitch bend controls send continuously during user gestures. Other button assignments send their fixed values. This is Studio-sent state only, not a verified reflection of changes made inside ARIA or by physical MIDI/playback.
7. Volume and pan operate the existing track VolumeAndPanPlugin; room trim updates the existing stage seat and send using SpatialRouting. Room is disabled unless a stage seat and room send already exist; no automatic effects or routing changes. The Rooms shortcut opens the existing workspace.

## Guardrails

Exact project generation, track ID, plug-in instance and snapshot identity are checked before sending. Unassigned bindings are disabled. No sends while recording, during pending ARIA recovery, plug-in insertion, frozen tracks or absent audio playback context. Live operation during ordinary playback is allowed; it is not sequenced or recorded by this milestone. Keyswitches release to the original still-existing instrument, not a replacement. The selected track must contain exactly one hosted instrument. Profile assignments remain disabled after replacing the original plug-in until reattached. A manual patch change inside the same ARIA instance cannot yet be detected, so reconfirm and reapply the profile after changing it. Channel mode CC 120–127 remain prohibited.

Project-local profile data persists in the track ValueTree property studioUniversalInstrument. Live feedback values are per-track session-only, cleared on project load and snapshot changes. No automatic MIDI chase or default-value transmission. Continuous bend/pressure/sustain values are intentionally live values rather than automatically reset after every drag. The fixed keyswitch pulse is not a full momentary/compound mapping implementation.

## Tests and scope

Extended StudioInstrumentProfiles tests cover attachment round-trip, replacement and version mismatch, invalid snapshot, independent track/channel values and articulation selection. Studio interface review adds actual compact and full component interaction tests for separate visibility, shared slider value, no emission on refresh, disabled unassigned element and articulation-only mode. CI filters cover M48 on Intel macOS and Linux. Native compilation/CTest and manual ARIA verification remain pending as of this commit.

The full view is floating in this milestone, not a new docked workspace. The existing native Sampler/Synth interfaces remain unchanged; live profile attachment is limited to hosted instruments. Designer edits remain separate from the project snapshot. Direct right-click assignment is in the Designer preview, not yet on the live surfaces. Utility choices are functional except an ostinato shortcut, which is not added until a matching workspace exists. No MIDI sequencing, playback chase, patch auto-detection, cross-library translation, compound switches or hardware MIDI feedback. M49 is local library reconciliation; M50 adds sequencing.
