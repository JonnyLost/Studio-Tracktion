# M37 — Workflow Refinement

Cumulative child of M36 136588f. Existing searchable command reference becomes actionable: search by musical tool or keyword, choose a matching command, Run/Return executes the existing action after dismissing the dialog. Shift-Command-P opens it; Command-5 opens instrument browser; Command-6 opens the selected instrument's original/native editor. Existing shortcuts retained. Navigate menu exposes Rooms, Virtual Microphones and direct editor. Track context menus expose selected instrument and inspector. No duplicate audio/track creation logic, no automated recording, no global key interception. Native editor opening continues through the existing instrument path. Region popup callbacks now guard against project generation changes. Double-click MIDI knobs resets their existing default value through normal callbacks (when enabled).

Interface review exercises command dispatch for Rooms, Microphones and Browser; verify keyboard focus and search/Run/Return in the actual modal on MacBook, no accidental action in text fields, selected instrument and frozen-track guards, and no project changes on navigation. Command list deliberately contains non-destructive navigation/settings commands only, not Save, Delete or Record. No customization or global shortcut remapping. Inherited M32 sampler and Unified Stage regressions remain; M36 CI pending at implementation time. No merges.
