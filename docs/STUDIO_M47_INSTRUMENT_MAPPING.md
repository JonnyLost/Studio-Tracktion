# M47 — Instrument mapping and MIDI Learn

Based on M46 b72a2a6a62dc34c3dd5fa8c836827323e83703e2 (Linux and Intel macOS PR CI passed on that revision). M47 adds profile assignment editing, hardware MIDI Learn and explicit audition through the original selected hosted instrument; it does not replace the existing articulation palette or install a new plug-in.

## Workflow

1. Load the exact ARIA patch on a Studio track, assign an enabled physical MIDI input to that track, stop playback and recording, and open Instruments > Instrument Designer. For a new profile, the selected hosted plug-in identifier and version are captured. Enter the exact patch name and slot/channel yourself. M47 does not inspect ARIA's internal keyboard or slot state.
2. Add an articulation/control or select one from the ordered elements list. Right-click its visible preview tile and choose Edit assignment, MIDI Learn, Audition saved assignment or Clear assignment. Elements outside the preview capacity remain editable using the list and assignment fields.
3. Choose Keyswitch, MIDI CC, Channel pressure, Pitch bend or Unassigned. For notes/controllers enter number 0–127; channel 0 follows the profile channel, or enter an explicit 1–16. Note velocity 1–127, CC and pressure 0–127, pitch bend 0–16383 (8192 center). Channel-mode CCs 120–127 are rejected. Note name display uses C4=60; trust MIDI numbers instead of assuming every vendor's octave labels agree. Click Save assignment, then Save profile.
4. MIDI Learn listens for the first valid note-on, controller, pressure or pitch-wheel event from physical MIDI devices already assigned to the selected track. It expires after 15 seconds, cancels on element/profile/context changes or closing the designer, and does not change routing or swallow normal MIDI. The captured channel and value are shown for review; click Save assignment to retain them. Clicking an ARIA virtual key is not guaranteed to generate an inbound event. No extra CoreMIDI port is opened.
5. Audition only after saving the assignment. Confirm the loaded patch and slot in the dialog. Audition is limited to a single initialized, enabled hosted instrument on the original selected unfrozen track with matching plug-in identifier/version, nonempty patch name and an active stopped playback context. It will refuse if the project or track/instrument identity changes, ARIA restoration is pending, the plug-in is being loaded, or recording/playback is active. Reopen the Designer on a different track to change its context. A keyswitch sends note-on then note-off after approximately 120 ms; pressure, bend and sustain auditions release/reset; other CCs retain their sent value. Cancellation releases to the original still-existing instance, never to a replacement. The user must confirm the audible result; this is not automatic patch detection.
6. Save the profile. Existing M46 schema-1 files migrate losslessly to schema 2 with unassigned bindings; subsequent saves write schema 2. Older Studio versions cannot read schema 2. Keep a backup if returning to M46.

## Architecture and scope

- InstrumentProfile.h: validated durable binding per stable layout element. Profile channel and explicit override are distinct. No assignments are inferred from M45.
- InstrumentMidiBinding.h: bounded message construction and one-shot atomic MIDI capture mailbox, no allocation or UI access in capture.
- InstrumentLearnInput.h: attaches only to existing enabled physical devices on the selected track; detaches on cancel and context invalidation.
- InstrumentDesigner.h: selected-element assignment fields, context menus and explicit audition confirmation. Existing transport and full instrument preview remain non-performance surfaces until M48.
- Studio.cpp: guard original project generation/track/plugin instance, matching hosted identity and transport safety; no new MIDI output device, no second ARIA instance, no clip edits. MIDI still travels through the track's established signal path (including existing MIDI processors).
- Tests: schema 1 migration, schema 2 roundtrip, malformed and reserved controller rejection, one-shot learning/filtering, explicit/follow channel and release messages; GUI review verifies assignment persistence. CI configured for both platforms; results are not claimed until the jobs finish.

M47 supports single-message note/CC/channel pressure/pitch bend bindings. No compound sequences, per-note pressure, program change, AU parameter learn, continuous fader performance, native sampler group mapping, verified-patch registry or project snapshots yet. The physical input route may itself sound a note during learn. The UI requires manual confirmation that the profile's patch is loaded; a matching plug-in identity cannot prove the internal patch. Standalone designs can be edited and saved but require a matching hosted identity to audition; create a profile from the target track if identity is absent. Profile labels for mixer concepts remain presentation-only until M48. There is no automatic claim that a learned key is an actual articulation.
