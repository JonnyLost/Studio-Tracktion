# Studio 0.2 — Native Synth and Sampler

Standalone JUCE/Tracktion Engine DAW for Intel macOS, based on the Mac-verified Studio 0.2 arrangement and automatic ARIA restoration milestone.

## Studio workspace

- **Project and transport** run across the top. Use **Start**, **Play/Stop**, and **Record**, with readouts for bars/beats, elapsed time, BPM, and meter. Space controls playback from the arrangement. Command-S saves and Command-Shift-S opens Save As. Save As creates a new `.tracktionedit` file, switches the current project to it, and refuses to overwrite an existing file.
- **Arrangement** stays above the dock. Use the track picker, track/clip creation and import buttons, and **Edit Regions** in the arrangement toolbar. Use **I** and **A** on a track for input and record arm, and **+** in Inserts to load an instrument or effect. Click the ruler to seek. Use the **− / +** next to **Tracks** or the toolbar's timeline zoom menu, which includes **Fit project**. Command-Z and Command-Shift-Z also work from the arrangement, and **Edit Regions** includes Undo and Redo.
- **Lower workspace** opens from the left rail and the transport's **MIDI Monitor**. **Compact** shows a workspace summary, **Split** restores the resizable editor, **Expanded** leaves a shallow arrangement above the editor, and **Hide** closes the dock. Drag the dotted divider or focus it and press Up or Down to resize in Split. A newly selected MIDI clip opens the Piano Roll from Compact. MIDI Monitor continues collecting while its own workspace is in Compact, and its **Float** and **Dock** actions remain available in the full monitor.
- **Studio Environments** opens a rotating illustrated welcome screen on launch. Choose **New Project**, **Open Project**, or **Continue to Studio**; browse five original scenes, choose favourites and rotation, or disable **Show at startup**. Reopen it from **View... → Studio Environments...**. Artwork settings are independent of project files. See [the Studio Environments guide](docs/studio-environments.md).
- **Planned workspaces** are labeled in the dock. **More** lists additional destinations. Stage, Rooms, and Microphones link to one another, and Channel opens the Studio Sampler or the installed hosted instrument. The existing arrangement Inserts and Plugin Manager are also available.

## Appearance and readability

Open **View...** in the top row. **Interface Scale** offers 100%, 110%, 125%, 150%, and 175%. **Text Size** offers Standard, Large (115%), and Extra Large (130%). Both apply immediately and are stored in Studio's application preferences. **Reset Appearance** restores both defaults. **Command–Option–=** and **Command–Option–−** step through interface sizes. **Command–Option–0** resets interface scale and keeps the text setting.

When space is tight, project controls move into **Project…**, arrangement commands into **Tracks…**, and dock controls into **Layout…**. MIDI Monitor is available from Project if it leaves the transport row. The rail and dock scroll as needed. At larger sizes the Browser puts filters in dropdowns and can stack details below results. Channel reflows its signal-flow cards, and Mixer scrolls the track bank horizontally while keeping Master pinned. Long names remain available through tooltips.

Appearance uses macOS logical points and native JUCE text layout. Retina backing scale, the musical timeline, Piano Roll time and pitch zoom, and waveform zoom are independent. Third-party plug-in editors and operating-system dialogs use their own scaling.

## MIDI expression, Articulations, and resources

- In **Piano Roll → Expression...**, enable any combination of CC1, CC11, CC7, CC64, Pitch Bend, and Channel Aftertouch. Lanes share the note timeline and snap grid. **Draw** writes stepped MIDI messages along the gesture. Sustain sends explicit off/on values with a single point per gesture. Pitch bend shows the signed offset from center and stores the full 14-bit value. Select a point to see its value, drag it to edit, or Shift-click to add points to the selected lane's selection. With a controller lane focused, use Command-A, Command-C, Command-V, and Delete. Paste uses the last lane click or the playhead if there is no lane cursor. It preserves events' relative timing and requires a matching destination clip channel. Undo and redo use project history. MPE data is read-only in these lanes.
- **Articulations** follows the selected track. **Pin track** keeps it on that track within the open project, across dock and float. Use a verified message and receiving channel from the instrument's patch documentation to add each mapping. The palette saves mappings with their instrument instance in the project and restores its layout and floating-window geometry from Studio preferences. Unknown patches start unmapped. Check existing mappings after changing a patch within the same plug-in instance. A pad or assigned Control-Command-digit auditions through the track's live route. **Insert at playhead** writes a controller event or short keyswitch note only to a selected clip with the matching track and channel. The optional shortcut is available while the palette is visible. Incoming MIDI triggers and recording live pad gestures to a take are deferred.
- **Resource Inspector** opens from **View...** or the transport CPU, RAM or XR readouts. The audio percentage is Tracktion callback utilization, while process CPU uses 100% per core. Peak fields are the highest sampled values since launch or reset. Studio footprint comes from macOS task information, total physical RAM from the system, and pressure from macOS memory-pressure notifications. XR is the device's native overload counter when supported. The instrument table is sortable and reports Unavailable for hosted instruments without attributable diagnostics. The app takes system samples at 2 Hz on the message thread and installs no additional audio callback. Device overload detection can vary by driver.

## Orchestral Stage, Rooms, and Microphones

Open **Stage** from the rail. Drag a seat or nudge it with the arrow keys. Shift moves the section. The track selector lets you pick overlapping seats and duplicate instrument names. **Auto Arrange** uses the selected Concert, Chamber, or Scoring preset and applies to all tracks, the arrangement selection, or the selected section. Stage settings travel with each Tracktion track and participate in project undo.

**Enable stage audio** is explicit and requires the transport to be stopped. Studio adds a stage balance and a post-fader aux send to one shared stereo room return. Existing faders and the track's direct output remain in the signal path. At the same send trim, the front row sends 10 dB less than the rear row. **Disable stage audio** removes that track's Studio balance and send. The shared return can stay in the project for other tracks. Studio checks for existing aux sends and recognized insert reverbs before enabling. This first implementation supports top-level tracks using the default audio output.

**Rooms** includes seven factory profiles and a project-specific custom library. Choose a preset or edit dimensions, surfaces, treatment, six octave trims, reflections, pre-delay, and return level. Use **Apply Room** to make the draft active. To duplicate a factory or custom design, enter a unique name and choose **Save copy**. The decay chart is a bounded Eyring estimate using generic materials. The wet-only DSP uses a shared eight-line modulated feedback network, input diffusion, and twelve early reflections. Room changes crossfade inside the existing DSP allocation. Bypass return immediately fades the wet signal while preserving the draft room design. Reset draft restores the wet defaults for the next Apply.

**Microphones** shows virtual capsule markers as diamonds, with pickup shapes and aim. Place and edit a capsule or add an XY, ORTF, spaced omni, or Blumlein pair and adjust spacing and angle. Save named setups in the project. The **Mic Mixer** stores level, pan, delay trim, mute, and solo for future capture. Studio stays in **Normal Mix**. Virtual microphone audio and Mic Audition are unavailable, so the capsule controls have no effect on recorded audio or the current mix. The shared-room bypass in that view controls the real return independently.

**Room signal check.** Stage displays the effective Tracktion send gain. Stage and Rooms show the shared DSP input and wet output levels. **Show return in Mixer** opens the Studio Room Return strip, where the fader and post-fader meter control and show the signal sent to Master. **Room Check +12 dB** temporarily raises the wet signal for up to 15 seconds. Stop it from either workspace, or bypass the room. The check does not become part of the saved project.

The original room output was substantially lower than the send and return trims suggested because the sparse taps and diffusion tank attenuated the wet signal in series. The corrected wet reference compensates for that loss while retaining the stored trims. At an equal send trim, depth still adds 10 dB from the front to the rear. Managed room returns are solo-safe so that soloing a source can retain its ambience.

Resource Inspector reports the native room's allocated delay-buffer bytes and Tracktion's callback-cost sample when available. Hosted plug-in memory remains separately attributed.

The [M4R acoustic comparison and MacBook listening procedure](docs/acoustic-engine.md) covers the original ringing, the revised engine, and how to generate paired offline renders.

The Swift [room-design prototype](https://github.com/JonnyLost/Garritan-studio/blob/fceed818b78d2ca8a6afcdc4312f0ae827a85903/docs/acoustic-room-designer.md) informed the six-band surface and treatment model. Its [wet-only reverb](https://github.com/JonnyLost/Garritan-studio/blob/fceed818b78d2ca8a6afcdc4312f0ae827a85903/docs/native-room-reverb.md) informed the feedback and early-tap design. The [mic geometry](https://github.com/JonnyLost/Garritan-studio/blob/864d26bdc133403678af8b861470544461ca0536/docs/virtual-recording-microphones-phase-1.md) and [experimental capture graph](https://github.com/JonnyLost/Garritan-studio/blob/864d26bdc133403678af8b861470544461ca0536/docs/native-microphone-spill-and-mixer-v1.md) informed placement, directional markers, stereo patterns, and explicit monitoring state.

## Instruments, Channel, and Mixer

- **Instruments** shows family, type, searchable results, and details with lightweight line artwork. On a compact window Type moves into the search toolbar. **Plug-ins…** opens the existing Tracktion/JUCE scanner. Results include native instruments and the scanned Audio Unit catalog. ARIA is shown as a hosted player. Open its actual editor from **Channel → Open Instrument** to select a Garritan library and patch. Studio Sampler is available alongside hosted instruments. Studio Synth exposes seven synthesis families alongside Studio Sampler.
- **Load on Selected Track** accepts one compatible unfrozen destination with no instrument, audio clips, or audio input. **Add as New Track** creates a new instrument track. The host confirms that the AU has an instance before either action changes the edit. A failed or timed-out load leaves the destination and its inserts intact. Existing instrument tracks remain available and can be used alongside the new track.
- **Channel** follows the selected track, including a clip or plug-in owned by that track. Assign or disconnect an enabled audio or physical MIDI device from the Input menus. Assigning MIDI uses the same auto-arm behavior as the arrangement input control. The physical MIDI device's channel filter and fixed Monitor settings apply device-wide. Automatic monitor mode follows Tracktion, and original MIDI events keep their channels. **Inserts** opens the exact instance or adds an effect before the track fader. **Sends** lists existing aux sends. **Output** selects the default or an enabled device and displays existing track-to-track destinations.
- **Mixer** scrolls track strips horizontally with Master pinned. A strip's name selects the arrangement track. Volume and pan share the Channel controls, and mute, solo, insert access and output selection use the same Tracktion track state. Meters read the existing Tracktion level meter inserts and default-output master measurer. An unavailable meter displays a dash, including on tracks without a meter insert. The mixer does not add meter inserts or change the routing graph when opened.
- The ARIA verification banner and save protection remain active. Browser and new effect insert actions wait until verification completes. Channel can open the restored instrument so you can check the patch and sound before confirming.

## Native instrument workspace

Studio Synth and Studio Sampler open in the lower workspace. Open an instrument from the Browser or Channel, then use the dotted divider to adjust its height. **Expand** gives the editor more room. **Float** moves it to a resizable window, and **Dock** brings it back. Selecting another native instrument track brings its editor forward while the project keeps playing. ## Studio Synth

Choose **Add Synth** from the instrument track menu, or choose a family in **Instruments → Synth**. **Browse Presets** opens all 201 original factory sounds, with name search, family and category filters, and a User library for saved sounds. **Sound** holds the main controls and playable keyboard. **Shape**, **Modulation**, and **Advanced** provide detailed editing. Save sounds as `.studiosynth` presets or with the Studio project. [Synth workflow and recovery notes](docs/native-synth.md)

## Studio Sampler

Choose **Studio Sampler** in Instruments and click **Add as New Track**. Drop a WAV or AIFF onto the waveform, then play the onscreen keyboard or a connected MIDI controller. Use **Basic** to shape the sound, **Mapping** to build key and velocity zones, and **Loops** to edit sustained playback. **Save Preset** creates a reusable `.studiosampler` file. Saving the Studio project also stores your current instrument settings. [Workflow and sampler architecture](docs/native-sampler.md)

## MIDI Piano Roll

1. Click a recorded MIDI clip in the arrangement. The editor opens automatically. Alternatively, select an instrument track, position the playhead, and click **+ MIDI Clip** to create a four-bar MIDI clip and open the editor.
2. Choose **Draw** to place notes. Drag during drawing to extend their duration. Choose **Select** to click a note and drag it horizontally or vertically. **Shift-click** notes to add/remove them from the selection, drag an empty area to draw a **selection lasso**, or press **Command-A** to select all notes in the active clip. Move, change velocities, quantize or delete the selected notes together. Drag either edge of the *active* note to resize it; group resize is not implemented. Escape clears the selection; Delete/Backspace deletes all selected notes in one undo transaction.
3. Drag a selected note's stem in the **Velocity** lane to change the selected notes' velocities by the same relative amount (clamped to MIDI range). Notes remain in place during the drag. Note and velocity-bar colors follow the same continuous color wheel from soft blue to hard red. The **Snap** menu places each triplet directly after its straight value (**1/4, 1/4 T, 1/8, 1/8 T, 1/16, 1/16 T, 1/32, 1/32 T**). **Quantize** snaps selected notes, or all notes if none is selected. **Undo** and **Redo** operate on Tracktion's project undo history. Command-Z and Command-Shift-Z work when the piano roll has keyboard focus.
4. The piano roll's measure/beat ruler uses the same project tempo sequence as the arrangement ruler. **Measure boundaries are strongest, beats medium, and selected snap subdivisions subtle**. Subdivision lines are anchored to **musical bar boundaries**, including when the MIDI clip has a source offset; drawing and quantization snap to those same visible positions. **Click a subdivision tick on the piano-roll ruler to seek the shared transport** without editing notes. Subdivisions and densely packed beat ticks disappear at wide zoom to avoid clutter, but **the selected snap value remains unchanged**. A blue **vertical playhead** moves through the notes and velocity lane whenever transport playback lies inside the selected clip. Both views read the same transport position; drawing refreshes at the UI timer rate, not sample by sample. Use the scrollbars to navigate beats and pitches. Shift-scroll moves horizontally. Command-scroll or **H+ / H-** adjusts horizontal zoom. **V+ / V-** adjusts piano-key height (vertical zoom) without jumping to a different pitch range. Click **Save**, quit, and reopen to verify edits persist.
5. Click a note or piano key at the editor's left edge to preview its pitch. Studio Sampler auditions directly on its track. Hosted instruments preview through an enabled MIDI input assigned exclusively to the clip's track. Preview retains the clip's channel and leaves input routing and stored MIDI intact.

When reopening a project containing ARIA, piano editing remains available. An **ARIA CHECK** reminder and **Retry ARIA / Confirm ARIA** controls appear directly below the transport. Studio blocks **both Save and Save As** until you have verified the restored ARIA slot sounds correct and clicked **Confirm ARIA**; a warning now explains this when you try to save. This protects the original AU state and backup. Editing a clip is not the same as confirming safe ARIA restoration.

## Region selection, dragging and editing

- In the arrangement, **Shift-click** other regions to extend or toggle the clip selection. The Tracktion example editor now passes these selections to Tracktion's native multi-selection manager.
- **Drag from the body of a region** to move it earlier/later on its track, or vertically to another compatible, unfrozen track. A translucent region preview shows the proposed drop; a red preview indicates that track cannot accept the drop. A selection of multiple regions moves together in time. Cross-track group drops are supported when all selected regions originate on the same track; mixed-source multi-track selections remain on their original tracks unless you move them individually. The model changes only on mouse release, in one Undo transaction.
- **Drag the first or last 8 pixels of a region** to trim its start or end without dragging its MIDI notes or audio source. The cursor becomes a horizontal resize indicator at either edge. The opposite edge remains in place. The trim uses Tracktion's native source-offset-preserving methods and enforces a small minimum region duration; double-check the contents of short clips after trimming.
- Arrangement dragging and trimming snap to the nearest **quarter-note beat**, using the project tempo map. **Hold Option** while dragging for unsnapped positioning and fine edge edits. This initial arrangement gesture grid is independent of the piano-roll Snap dropdown; a shared user-configurable region grid is still planned. The translucent preview remains on the source track until the cursor enters another valid track.
- With multiple MIDI regions selected, the piano roll displays the earliest region as the **active, editable take** and other regions as translucent **read-only ghost notes** at their corresponding project times. The caption identifies the additional clips; click one region alone to make it the editable take. This preview is not simultaneous multi-clip editing.
- **Edit Regions** in the arrangement toolbar opens **Split selected at playhead**, **Duplicate selected**, **Copy**, **Paste**, **Cut** and **Delete**. Split uses Tracktion's clip-splitting API so existing source offsets and take data are retained. Duplicate inserts a separate clip after each selected source. Copy retains multiple clips and their relative time and track offsets. Paste inserts them at the transport position; select a destination track before pasting to place the group at that track and subsequent tracks. The clipboard clears when you open or create another project. Missing destination tracks are not created automatically.
- **Limitations:** Arrangement lasso selection, group resizing, simultaneous editing of ghosted MIDI clips, and MIDI or audio **Join** are not yet implemented. Joining MIDI must include CC/pedal/expression data, and joining audio requires a safe render/comp strategy. Dragging is limited to visible tracks (no automatic scroll while dragging), and audio clips cannot appear as notes in the piano roll. The new region operations must be tested on copies of projects before being treated as production-safe.

After stopping an Oxygen 25 recording, saving waits until the Tracktion transport completes its recording-stop transition, with a bounded timeout rather than writing a partially finalized take. If it cannot finish safely, Studio leaves the existing file untouched and reports the failure.

All note changes use Tracktion's undo-aware MIDI sequence APIs on the message thread. The editor updates the active take of the underlying MIDI clip. It preserves its MIDI channel, plugin state, and audio routing. Looping clips show the editable source sequence, so edits affect every repetition of that take. MIDI notes beyond the visible window can be reached by scrolling.

## Build and launch on Intel macOS

Quit any running Studio instance. Run these commands once on macOS 14 or later with Xcode and CMake installed. The new folder keeps this test build separate from any current Studio checkout.

```bash
mkdir -p "$HOME/Developer" &&
cd "$HOME/Developer" &&
git clone --branch feature/studio-unified-instruments-m65 https://github.com/JonnyLost/Studio-Tracktion.git Studio-Tracktion-Milestone65 &&
cd Studio-Tracktion-Milestone65 &&
git init build/deps/tracktion-engine &&
git -C build/deps/tracktion-engine fetch --depth 1 https://github.com/Tracktion/tracktion_engine.git c6293127cdc0a8488aea2ae0907f4709ee89c228 &&
git -C build/deps/tracktion-engine checkout --detach FETCH_HEAD &&
git -C build/deps/tracktion-engine -c url.https://github.com/.insteadOf=git@github.com: submodule update --init --depth 1 &&
/Applications/CMake.app/Contents/bin/cmake -S . -B build -G Xcode \
  -DTRACKTION_ROOT="$PWD/build/deps/tracktion-engine" \
  -DCMAKE_OSX_ARCHITECTURES=x86_64 \
  -DCMAKE_OSX_DEPLOYMENT_TARGET=14.0 &&
/Applications/CMake.app/Contents/bin/cmake --build build --config Debug --target Studio --parallel 4 &&
open "$PWD/build/Studio_artefacts/Debug/Studio.app"
```

Use `cmake` in place of the CMake.app path if CMake is installed on your PATH.

### Verification boundary

Intel macOS CI builds Studio with Xcode and runs the appearance, MIDI, articulation, resource, spatial state, DSP, and Tracktion routing tests. The automated spatial tests exercise the wet-only DSP as well as Tracktion's MIDI-to-instrument-to-Master graph through a hosted stereo device in memory.
